## 中文

### AI 实用工具与工作流

让 AI 更好用：先解决一个具体问题，再决定是否值得加入你的日常工作。

- **[AI Quota](AI%20Quota/)**：把多个AI订阅的剩余额度放进一个Mac窗口，开始工作前少翻几个官网。[下载应用](https://github.com/LevinShi/AGI/releases/tag/ai-quota-v0.5.1)
- **[deep-research](deep-research/)**：给重要研究加上来源核对、反证与未知项，让结论更容易复核。[了解配置](deep-research/docs/SETUP.md)

两个项目独立使用。前者是应用，后者是Codex技能包；不需要为了使用其中一个安装另一个。

## English

### Practical AI tools and workflows

Start with a specific problem. Add a tool to your routine only if it helps.

- **[AI Quota](AI%20Quota/#english):** See remaining allowances across AI subscriptions in one Mac window, without opening every provider’s website. [Download the app](https://github.com/LevinShi/AGI/releases/tag/ai-quota-v0.5.1).
- **[deep-research](deep-research/#english):** Add source verification, counterevidence, and explicit unknowns to important research. [Check the requirements](deep-research/docs/SETUP.md).

The projects are independent: one is a desktop app, the other a Codex skill. You do not need to install both.
