# AI Quota

项目位于 [LevinShi/AGI](https://github.com/LevinShi/AGI) 的 `AI Quota/` 目录；当前桌面应用名称为 **Quota Desk**。

一个本地运行的 macOS AI 订阅额度看板。把多个产品的**剩余百分比、5 小时／周／月额度和下次恢复时间**放在一个常规桌面窗口中，适合同时使用多个 AI 订阅、希望快速判断哪个账户还有额度的人。

当前版本：0.5.1。独立个人项目，与下列 AI 厂商无隶属或官方合作关系。

## 下载与使用

发布包 `QuotaDesk-v0.5.1-macos-arm64.zip` 适用于 **Apple Silicon（M 系列芯片）Mac，macOS 13 或以上**。当前没有 Intel 或通用版本；最低系统版本声明不代表已在所有系统版本完成测试。

1. 解压 ZIP，将 `Quota Desk.app` 拖到“应用程序”，也可以直接从解压目录运行。
2. 打开 App，在各产品的官方客户端或支持的浏览器中登录自己的账号。
3. 点击单个产品的刷新按钮，或“全部刷新”。打开官网本身不会自动建立额度读取能力，具体前提见下表。

**无需安装向导，无需另装 Node.js。** 运行环境随包附带；各厂商的客户端、CLI 和 Tabbit 不随包提供，需要按实际使用的产品准备。App 是普通 Dock 应用，关闭窗口后可从 Dock 再次打开，退出使用 Command-Q。没有自动开机启动或常驻系统服务。

发布包采用本地临时签名，**尚无 Apple Developer ID 签名及公证**。从互联网下载后 macOS 可能阻止打开。确认来源可信后，可按系统提示在“系统设置 → 隐私与安全性”允许该应用；如果设备受组织管理，请遵从设备策略。不要关闭整个系统的安全保护。

## 功能与计算口径

- 完整产品名称、订阅档位、可手动调整并保存的产品顺序。
- 统一展示剩余百分比：`剩余 / 总额度 × 100%`；官方只给已用百分比时使用 `100% − 已用百分比`。
- 5 小时、周、月是**分类视图**，不会把周额度按时间比例虚构成月额度。没有对应额度显示“不适用”；应该存在但读取不到则显示未知或错误。
- 下次恢复使用北京时间（Asia/Shanghai，UTC+8），与电脑时区无关。官方没有提供时保持未知。
- 同一产品的不同额度池分别保留；Kimi 月度总量包含 Code 贡献，不重复累加。赠送／额外积分不混入月度分母。
- 每个账户每 24 小时尝试自动更新一次，运行期间检查；退出期间不运行，重新打开后按上次尝试时间判断。手动刷新可随时触发，短时间重复点击会被限制。
- 失败时保留旧值并标明状态；过了重置时间不会自行假设已恢复到 100%。因此这是每日快照看板，不是持续实时计费工具。

## 已实现的产品与接入前提

以下表示代码中已有读取路径，不保证厂商未来版本、所有地区、所有订阅档位都兼容。不同机器仍需逐项验证自己的登录状态。

| 产品 | 当前可读取的口径 | 实现方式与前提 | 主要边界 |
| --- | --- | --- | --- |
| ChatGPT（Codex） | Codex 返回的 5 小时／周等限制窗口、档位 | 本机已登录 Codex CLI；通过官方 `app-server` 的 `account/read` 与 `account/rateLimits/read` 读取 | 不等于 ChatGPT 聊天或 Work 的全部用量；需让 App 能找到 `codex` |
| Cursor | 月度总量与模型分类额度 | 只读 Cursor 自有本地登录数据库，向固定官方账户接口查询 | 目前面向个人账户；团队或不同套餐的口径可能不同 |
| Kimi | 综合会员月度总用量、Code 5 小时与 7 天限制 | 先尝试官方桌面登录；失效时通过已登录的 Tabbit 网页查询官方综合会员统计，认证信息留在浏览器内 | 月度需要有效桌面会话或 Tabbit 网页登录；只有 Code 登录时独立更新短周期，月总量保留旧值和原读取时间，无历史时明确显示待读取 |
| MiniMax | Token Plan／M Token Plan 的 5 小时、周额度 | 已登录 MiniMax Code，优先通过本地认证服务临时取凭证；不可用时读取其尚未过期的指定本地凭证，再访问固定额度接口 | 含中国站／国际站域名分支，实际验证主要为中国站；建议保持官方客户端运行，认证服务版本变化可能影响接入 |
| ZCode（智谱） | Coding Plan 的 5 小时、周额度 | 读取 ZCode 自有凭证文件，在内存中处理后向 BigModel 固定额度接口查询 | 只对应 Coding Plan；官方未提供的恢复时间不推算 |
| Grok Bot | 当前接入路径返回的周额度 | 使用 Cursor 关联登录与其官方仪表盘接口 | 不等于 Grok 网页聊天或任意 xAI 订阅的通用额度接口 |
| YouMind | 月度积分余额、总额、消耗比例、刷新时间；额外积分单列 | 安装 Tabbit 与 `tabbit-cli`，在 Tabbit 登录 YouMind，CLI 位于 `~/.local/bin/tabbit-cli`；在同源网页调用官方积分查询接口 | 总分以账户接口返回值为准，**不硬编码 4,000**；免费日额度不冒充月额度 |
| Muse.ai | 官方返回的周期用量百分比、恢复时间与额外余额比例 | 安装 Tabbit 与 `tabbit-cli`，在 Tabbit 登录 Muse.ai；调用其网页订阅读取操作 | 网页操作标识可能随发布变化；内部单位不宣称是 token；与 Muse Code 不是同一连接器 |

Gemini 暂时隐藏，没有可用的自动读取连接器。Claude、OpenCode Go 等仅保留扩展方向，不属于已经接通的产品。支持多张账户卡片不等于同一厂商的多个登录身份已实现自动隔离；当前连接器通常读取本机当前登录。

浏览器读取仅支持当前实现的 Tabbit 路径，不会自动读取任意 Chrome／Safari 登录。Tabbit 及其 CLI 应从其可信官方渠道安装，本项目不附带浏览器二进制。

## 隐私与安全

### 数据在哪里

App 的前端、Node 后端和额度缓存都在本机运行。后端只监听 `127.0.0.1` 的随机端口，并检查请求来源和会话授权标记。项目没有自己的云端账户服务或遥测上传，不读取对话内容、代码仓库或任务历史。

额度、订阅档位、自定义账户名称、排序、刷新时间保存在 `~/Library/Application Support/Quota Desk/quotas.json`。缓存采用当前用户可读写的文件权限，但**不是加密数据库**。额度本身也属于使用行为信息；共享电脑、备份或截图时应自行考虑可见范围。系统还可能保存窗口位置等偏好。

发行 ZIP 和源码导出不包含开发者的登录信息、实际额度缓存、账户截图、浏览器资料、私人报告或本机路径配置。测试数据为合成示例。安装后只会使用接收者自己的本地登录状态。

### 凭证如何使用

部分厂商没有公开的订阅额度 API，因此连接器需要临时使用已登录官方客户端的凭证。读取范围限定到相应客户端的指定文件、cookie 或本地认证服务；不会扫描其他浏览器资料或要求将密码上传给本项目。凭证在内存中用于固定官方域名请求，不写入额度缓存，不作为额度结果返回界面。

浏览器连接器利用已经登录的同源页面查询，并只返回允许的额度字段；不会导出完整 cookie 或完整账户响应。官方应用和浏览器本身的隐私政策、日志与网络行为仍由各自产品决定。

这并不代表零风险：认证凭证的权限可能大于“只读额度”；被篡改的程序、恶意依赖或同一用户权限下的其他程序仍可能滥用凭证。本地端口检查也不是针对本机恶意程序的完整隔离。请只使用可信发布包，检查校验和，避免向公开 issue 粘贴 cookie、token、完整日志或账户截图。

### 厂商政策与账号风险

部分读取方式使用网页内部接口或客户端内部协议，**不是厂商对第三方工具作出的兼容性或授权承诺**。用户授权本程序读取自己的账户，也不自动替代厂商服务条款。接口可能变化，自动访问可能触发登录过期、验证码、限流或账号风控，无法承诺不会封号。每天一次查询减少访问频率，但不能消除这些风险。

本项目不绕过验证码、访问控制或付费限制，不执行模型请求来估算用量，不通过批量重试对抗限流。遇到验证或拒绝访问时应回到官方客户端处理；不接受这一风险的用户应只使用其认可的接入方式或官方页面。

## Kimi 月度总量（0.5.1 修复）

Kimi 月度总量指综合会员的 Kimi + Code 总用量。桌面凭证失效时优先尝试 Tabbit 官方网页登录；仍不可用则保留月总量及其原始读取时间，明确标记更新失败，绝不使用 Code 刷新时间伪装月总量已更新。5 小时和周额度独立更新；折叠视图优先显示 Kimi 月额度。没有历史记录时显示“月总量待读取”。

## 常见问题

**显示已登录但没有额度？** 登录只满足一项前提。核对上表所需客户端、CLI、地区与套餐；打开对应官方客户端确认订阅页正常，再单独刷新。出现接口格式错误可能需要升级连接器，不应填写不明来源的 token。

**为什么官方显示“已用”，本应用显示“剩余”？** 本应用统一使用剩余比例，二者互补。额外积分与月度积分可能拥有不同重置机制，不能直接相加比较。

**如何清除数据／卸载？** Command-Q 退出后，删除 App；如果还要删除本应用缓存，删除上面列出的 `Quota Desk` 数据目录。这不会退出或清除各厂商客户端的账号。

**是否支持会话跟进、自动处理待办？** 当前版本只做账户额度，不包含会话监控或消息发送。

## 从源码开发与构建

需要 macOS、Xcode Command Line Tools（含 Swift 编译器）、Node.js 22 或以上。运行时没有额外 npm 包依赖。

```sh
npm test
npm start
npm run build:desktop
npm run build:release
npm run export:source
```

`npm start` 启动本地网页服务用于开发；`build:desktop` 生成依赖本机 Node 的开发 App；**只分发 `build:release` 生成的 release ZIP**，不要分发开发构建。

发布构建复制正在运行构建脚本的 Node 可执行文件，并要求其安装根目录提供完整 `LICENSE`。使用可信的官方 Node 发行版；CPU 架构跟随构建机器，不会自动跨平台编译。发布产物包括 ZIP 和 SHA-256 校验文件。ZIP 外层附带本说明与许可，App 内也附带 Node 许可。

`export:source` 按明确文件清单导出可发布源码到 `dist/source/quota-desk`，排除本地数据、开发报告及截图。

架构为 Swift/AppKit 窗口 + WKWebView、原生 JavaScript 界面、仅本机监听的 Node 服务和按厂商拆分的连接器。`src/catalog.js` 定义产品，`src/domain.js` 统一口径，连接器负责读取并校验额度，`src/service.mjs` 管理缓存、失败状态和刷新节奏。

新增产品应提供：固定官方请求范围、明确的登录前提、仅含额度的返回字段、原始周期到统一视图的映射、缺失字段与重置边界测试。优先使用官方稳定接口；不能证明分母或周期时返回未知，不推算虚假百分比。不得把真实账号数据提交为测试样本。
